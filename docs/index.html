SLA-Aware Inference Gateway

A gateway that keeps image-classification latency inside a 300 ms SLA by routing each request between an accurate ResNet-50 (int8 ONNX) and a fast MobileNetV3, based on live p95 latency. Built from scratch and measured end to end under load.

Load
Open-loop Poisson traffic of real ImageNetV2 images, accuracy measured per answer
Route
SLA controller on rolling p95 · adaptive concurrency limit · circuit breakers · deadline propagation
Serve
accurate: ResNet-50 v2 int8 (68.8%) · fast: MobileNetV3 fp32 (60.6%), ONNX Runtime on 2 CPUs each
Operate
Canary 10→50→100% with auto-rollback · shadow traffic · Prometheus/Grafana/Jaeger · Kubernetes HPA

Problem

At twice its capacity a single accurate model collapses: p95 latency of 2.7 s, 27% of requests failing, and 0.4% answered within the SLA. Always using the small model avoids that at a permanent 8-point accuracy cost.

What I built

The whole system: ONNX export and int8 quantization of 8 candidate models evaluated on 9,500 held-out images, the model servers, the gateway and its control loop, canary rollouts, an open-loop load generator, Docker Compose and kind/HPA deployments, and the benchmark suite (34 tests).

Result

2,721 → 192 msp95 at 2× capacity, with 99.8% of requests within the SLA and zero errors, while keeping accuracy 4 points above the always-fast option. A faulty canary was rolled back in 16 s with no client-visible errors. Found and fixed a CFS-throttling issue in ONNX Runtime that cut p95 by 3.8×.

Multimodal ML for Myeloma Treatment Response

Predicting how multiple myeloma patients will respond to treatment by combining clinical tables, flow cytometry, bone-marrow variables, and PET/CT imaging, and explaining what drives each prediction.

Data

Encode
TabTransformer, ClinicalBERT, ResNet-18, 3D U-Net
